# FUTURE_DS_03

# Marketing Campaign & Conversion Performance Analysis

### 📌 Project Overview

This project focuses on analyzing Bank Marketing campaign data using Python and Microsoft Power BI to understand customer contact performance, subscription patterns, campaign effectiveness, and conversion rates.

### 🎯 Objective

To evaluate marketing campaign performance, identify subscription trends, analyze customer responses, and understand which contact channels, months, and job categories contribute most to successful subscriptions.

### 🛠️ Tools Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Microsoft Power BI
- Power Query
- DAX
- Bank Marketing Dataset (CSV)

### 📊 Key Analysis

- Overall Marketing Campaign Analysis
- Total Customer Contacts
- Successful and Unsuccessful Subscriptions
- Monthly Subscription Trends
- Subscription by Job Category
- Campaign Contact Analysis
- Contact Channel Performance
- Subscription Outcome Analysis
- Conversion Rate Analysis
- KPI Monitoring:
  - Total Contacts
  - Total Subscriptions
  - Not Subscribed
  - Conversion Rate

### 📁 Files Included

- Python Jupyter Notebook (`.ipynb`)
- Cleaned Bank Marketing Dataset (`.csv`)
- Power BI Dashboard (`.pbix`)
- Dashboard Screenshot (`.png`)

### 💡 Project Outcome

The dashboard provides an overview of marketing campaign performance, customer subscription patterns, and conversion rates. It helps identify customer response trends and supports data-driven marketing decisions.
